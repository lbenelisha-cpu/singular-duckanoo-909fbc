# IML Control — Sprint 11.5.0 Build 1

## שיפורי ביצועים
- מסנן ברירת מחדל: 7 הימים האחרונים.
- הצגה מיידית של מטמון IndexedDB, לפני הסנכרון לענן.
- בדיקת metadata של ארבעת מקורות הנתונים והורדה רק כאשר הגרסה השתנתה.
- Production נטען ראשון; Targets, Quality ו-Deviations נטענים בהדרגה ברקע.
- מניעת בקשות כפולות באמצעות in-flight request deduplication.
- עדכון Realtime מוריד רק את סוג הנתונים שהשתנה.
- הגדלת עמוד הורדת המקטעים מ-12 ל-100 לצמצום קריאות API.
- מסך בדיקת הרשאות לפני הצגת הדשבורד; אין מעבר זמני ל-Viewer.
- Diagnostics למנהל: Cache, Queries, Rows, Load Time וטווח ברירת המחדל.

## הערת ארכיטקטורה
הנתונים נשמרים כיום ב-Supabase כמקטעי JSONB. לכן סינון תאריך אמיתי בצד השרת אינו אפשרי ללא מיגרציה לטבלה שורתית. Build 1 מצמצם הורדות חוזרות באמצעות גרסאות ומטמון; Build המשך יוכל להוסיף טבלת אינדקס/סיכומים לתמיכה בשליפה פיזית של 7 ימים בלבד.
