IML CONTROL — עדכון Short Description בדוח Excel

קובץ להחלפה:
src/DashboardApp.jsx

מה השתנה:
1. עמודת "קו יצור" בגיליון "דיווח יומי פורמולציות" מציגה Short Description בכל המתקנים.
2. אם Short Description אינו קיים ברשומה, המערכת נופלת ל-Routing Description ורק לאחר מכן ל-Routing Group.
3. בזמן טעינת קובץ תפוקה חדש, Short Description נשמר גם בנתונים הקומפקטיים לענן.

הערה:
אם הנתונים שכבר נמצאים בענן נטענו לפני העדכון ואינם מכילים Short Description, יש לטעון מחדש את קובץ התפוקה כדי לשמור את השדה החדש.
