IML CONTROL — Batch + Material Quality Patch 1
==============================================

מטרת התיקון
------------
תוצאות איכות בכרטיס המנה מזוהות אך ורק לפי החוק של המפעל:

    Batch + Material

לא נעשה שימוש ב-Order, Inspection Lot, Routing Group, תחנה או מתקן לצורך בחירת תוצאות האיכות.
הערכים האלה ממשיכים להיות מוצגים בכרטיס בדיוק כמו היום.

מה התיקון משנה
---------------
1. מוסיף אינדקס איכות ישיר לפי Batch+Material.
2. כרטיס המנה מושך תוצאות איכות רק מהמפתח המדויק הזה.
3. רשומות תפוקה בכרטיס מסוננות לפי אותו Batch+Material.
4. רשומות חריגה בכרטיס מסוננות לפי אותו Batch+Material.
5. כפתורי Batch מעבירים מאחורי הקלעים גם את Material.
6. תצוגת Batch Control Center לא משתנה.
7. נוצר גיבוי אוטומטי של DashboardApp.jsx לפני השינוי.

איך מתקינים
------------
1. חלץ את הקובץ ZIP.
2. העתק את apply_batch_material_patch.mjs אל התיקייה הראשית של הפרויקט שלך,
   אותה תיקייה שמכילה את src.
3. פתח Terminal בתיקייה הראשית והריץ:

    node apply_batch_material_patch.mjs

4. אם מופיע PATCH_OK, הרץ:

    npm run dev

5. בדוק מנה שבה אותו Batch מופיע במספר מק"טים.
   הכרטיס צריך להציג רק את המק"ט שנבחר ואת תוצאות האיכות שלו.

חשוב
-----
הסקריפט אינו מחליף את הפרויקט ואינו מוחק שינויים אחרים.
הוא משנה רק את src/DashboardApp.jsx ויוצר לידו קובץ גיבוי BEFORE_BATCH_MATERIAL.
