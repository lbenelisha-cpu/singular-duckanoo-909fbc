# IML Control — Sprint 10.1 Enterprise Data Engine

## מה חדש
- כל טעינה יוצרת גרסה חדשה ונפרדת.
- הנתונים הקיימים נשארים פעילים בזמן ההעלאה.
- העלאה מתבצעת במקטעים ומציגה אחוז התקדמות.
- לפני הפעלת הגרסה מתבצע אימות של מספר המקטעים והרשומות.
- רק לאחר אימות מלא מתבצעת החלפה אטומית לגרסה החדשה.
- במקרה של כשל הגרסה מסומנת Failed והגרסה הקודמת נשארת פעילה.
- נשמרים מספר גרסה, זמן טעינה ותוצאת הטעינה בהיסטוריה.

## התקנה
1. ב-Supabase פתח SQL Editor.
2. הדבק והריץ את `SPRINT_10_1_INSTALL_SUPABASE.sql`.
3. העלה את כל קבצי הפרויקט ל-GitHub.
4. ב-Netlify בצע Clear cache and deploy site.
5. לאחר הכניסה ודא שמופיע `Sprint 10.1 — Enterprise Data Engine`.

הסקריפט בטוח להרצה חוזרת.
