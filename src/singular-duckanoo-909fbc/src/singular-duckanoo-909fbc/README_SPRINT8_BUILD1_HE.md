# Sprint 8.1 – Build 1

## מה נוסף
- מרכז נתונים עם ארבעה מקורות נפרדים: תפוקות, תוצאות איכות, חריגות איכות ויעדים חודשיים.
- טעינה ייעודית לכל סוג קובץ, לצד הטעינה האוטומטית הקיימת.
- בדיקת עמודות חובה לפני הכנסת הנתונים למערכת.
- הצגת שם הקובץ, מספר הרשומות, מועד הטעינה ומספר המתקנים שזוהו במדגם.
- שמירת פרטי הטעינה ב-IndexedDB יחד עם הנתונים.
- שמירה על תאימות לנתוני Sprint 7 הקיימים בדפדפן.

## סדר בדיקה מומלץ
1. להעלות ל-Netlify.
2. לפתוח את מרכז הנתונים.
3. לטעון כל קובץ באזור המתאים.
4. לוודא שכל ארבעת הכרטיסים הופכים ל״תקין וזמין״.
