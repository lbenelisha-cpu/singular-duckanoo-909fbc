# Sprint 11.1.1 — כניסה כאורח לצפייה בלבד

## מה נוסף

- כפתור **כניסה כאורח — צפייה בלבד** במסך הכניסה.
- אורח מקבל אוטומטית תפקיד `viewer`.
- כפתורי טעינת Excel, מחיקה ושינוי נתונים נשארים מוסתרים וחסומים.
- אורח יכול לצפות, לסנן, לחפש ולייצא.
- יציאה מאורח מסיימת רק את ההתחברות המקומית בדפדפן.

## פעולה חד-פעמית ב-Supabase

1. פתח Supabase Dashboard.
2. עבור אל **Authentication → Providers** (או Sign In / Providers, לפי תצוגת הממשק).
3. פתח **Anonymous Sign-Ins**.
4. הפעל את האפשרות ושמור.

אין צורך להריץ SQL נוסף: מדיניות ה-RLS הקיימת מאפשרת קריאה למשתמשים מחוברים, אך פעולות כתיבה דורשות תפקיד מנהל.

## פריסה

העלה את הקבצים ל-GitHub וב-Netlify בצע **Clear cache and deploy site**.
