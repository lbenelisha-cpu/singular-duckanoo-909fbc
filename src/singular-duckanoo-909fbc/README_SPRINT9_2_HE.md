# Sprint 9.2 — Cloud First

## מה נוסף
- ארבעת מקורות הנתונים נשמרים ב-Supabase ולא רק בדפדפן.
- כל משתמש מחובר טוען את אותם נתונים משותפים בעת הכניסה.
- IndexedDB נשאר כגיבוי מקומי בלבד למקרה שאין חיבור.
- חיווי ברור: ענן / מתחבר / מצב מקומי / שגיאת סנכרון.
- טעינה ומחיקה בענן זמינות רק למנהל מערכת.
- היסטוריית טעינות נשמרת במסד.

## התקנה חד-פעמית
1. פתח Supabase > SQL Editor.
2. הרץ את `supabase_cloud_schema.sql`.
3. העלה את הפרויקט ל-GitHub/Netlify ובצע Deploy.
4. היכנס כמנהל וטען מחדש את ארבעת קובצי Excel.

הנתונים הישנים ב-IndexedDB אינם מועלים אוטומטית. הטעינה הראשונה של כל קובץ לאחר השדרוג מעבירה אותו לענן.
