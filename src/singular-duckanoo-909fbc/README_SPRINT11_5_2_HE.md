# Sprint 11.5.2 — Resource Mapping Engine

## עיקרי הגרסה
- מיפוי מרכזי לפי `Storage Location + Description`.
- מתקן 42 מחושב רק לפי התאמה מדויקת ל־Description.
- ערכי ברירת מחדל: LIQUID 1/5/10/20 LITER.
- Description שאינו מוכר אינו נספר בטעות לקו אחר.
- Mapping Monitor מציג תיאורים, רשומות וכמויות שלא מופו.
- מסך מנהל לעריכה, הוספה, מחיקה ושמירת מיפויים.
- המיפויים נשמרים בדפדפן ומשפיעים מיד על Control Tower והתחזית.
