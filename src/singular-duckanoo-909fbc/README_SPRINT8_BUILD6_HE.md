# Sprint 8.2 – Build 6: Batch Control Center

## מה נוסף
- כל מספר Batch בטבלאות תפוקה, איכות וחריגות הפך ללחיץ.
- כרטיס מנה אמיתי המבוסס על הנתונים הטעונים ולא על נתוני דמו.
- איחוד נתוני תפוקה, איכות וחריגות לפי Batch באמצעות Batch Index פנימי.
- פרטי מנה, כמות, מתקן, Order, Material, Routing group ו-Inspection Lot.
- תוצאות איכות מלאות עם סינון: הכול / תקינים / חריגים.
- Timeline למנה: ייצור/אריזה, בדיקות איכות, החלטת QA ושחרור.
- הצגת חריגות והערות המקושרות למנה.
- ייצוא Excel ייעודי למנה.

## בדיקה
טען את שלושת מקורות הנתונים, עבור לטבלת תפוקה/איכות/חריגות ולחץ על Batch.
