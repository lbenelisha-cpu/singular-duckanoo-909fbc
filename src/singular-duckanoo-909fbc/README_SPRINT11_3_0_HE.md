# Sprint 11.3.0 – סינון איכות ושעת דגימה

## שינויים
- מסנן התאריכים ממשיך להשפיע על תפוקה, איכות ומנות חריגות.
- תאריך ושעת הדגימה נקראים מקובץ האיכות, כולל תמיכה בשמות עמודות נפוצים בעברית ובאנגלית.
- בטבלת תוצאות האיכות נוספו תאריך דגימה ושעת דגימה.
- בטבלת המנות החריגות נוספו תאריך דגימה ושעת דגימה, בשיוך לפי Batch ובעדיפות ל-Inspection Lot תואם.
- הרשומות ממוינות מהדגימה החדשה לישנה.
- לחיצה על Batch ממשיכה לפתוח את כרטיס המנה.
