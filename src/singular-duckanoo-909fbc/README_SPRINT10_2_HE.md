# Sprint 10.2 — Stable Pagination Data Engine

גרסה זו מתקנת את שגיאת `canceling statement due to statement timeout`.

## מה השתנה

- קריאת JSONB מהענן ב־12 מקטעים בלבד בכל בקשה, במקום עד 500.
- טעינת Excel לענן במנות קטנות של עד 450 רשומות בכל בקשה.
- Retry אוטומטי עם השהיה מדורגת במקרה של timeout או תקלה זמנית ברשת.
- `upsert` בטוח, כך שניסיון חוזר אינו יוצר כפילות.
- אימות הרשומות מתבצע בצד PostgreSQL כחלק מהפעלת הגרסה, ללא הורדת אלפי רשומות אימות לדפדפן.
- פס ההתקדמות מציג גם את הורדת הנתונים מהענן.

## התקנה

אין צורך להריץ SQL חדש אם שלוש בדיקות ההגירה כבר החזירו `true`.

1. העלה את הפרויקט ל־GitHub.
2. ב־Netlify בחר `Clear cache and deploy site`.
3. רענן את האתר עם `Ctrl+Shift+R` או `Cmd+Shift+R`.
4. טען מחדש את קובץ תוצאות האיכות המלא. הגרסה הישנה שמכילה 6,000 רשומות תוחלף רק לאחר שהטעינה החדשה תושלם ותאומת.
