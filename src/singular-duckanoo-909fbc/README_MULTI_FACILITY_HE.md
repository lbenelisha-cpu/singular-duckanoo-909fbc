# Sprint 5 – בחירת מספר מתקנים וסנכרון איכות

## שינויים
- ניתן לבחור כמה מתקנים במקביל באמצעות לחיצה על כרטיסי המתקנים.
- לחיצה נוספת על מתקן נבחר מסירה אותו מהבחירה.
- סינון התפוקה, המשמרות, הגרף והטבלה מתבצע לפי כל המתקנים שנבחרו.
- נתוני האיכות מסוננים לפי `Inspection Lot Storage Location` או `Process Order Storage Location`, בהתאם למתקנים שנבחרו.
- מנות חריגות מסוננות לפי מתקן וקווי הייצור המקבילים.
- יצוא Excel כולל רק את התפוקה, האיכות והחריגות של המתקנים שנבחרו.

## העלאה
העלה את כל תוכן התיקייה לשורש מאגר GitHub, בצע Commit והמתן לפרסום ב-Netlify.
