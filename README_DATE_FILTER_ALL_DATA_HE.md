# עדכון מסנן תאריכים — תוצרת, איכות ומנות חריגות

בוצע עדכון כך שמסנן התאריכים הראשי משפיע באופן אחיד על:

- נתוני תוצרת / אריזה
- תוצאות איכות לא תקינות
- מנות חריגות פתוחות

בנוסף, טווח התאריכים הזמין בבורר מחושב כעת מכל שלושת מקורות הנתונים ולא רק מקובץ התוצרת.

## דוגמה
בחירה ב־"יום אחרון" תציג רק רשומות תוצרת, איכות ומנות חריגות שתאריך הרשומה שלהן נמצא ביום האחרון הזמין במערכת.
