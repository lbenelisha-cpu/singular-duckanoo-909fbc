# Sprint 11.2.2 — צפייה ללא חשבון

## מה השתנה
- כפתור **צפייה בלבד** אינו משתמש עוד ב־`VITE_VIEWER_EMAIL` או `VITE_VIEWER_PASSWORD`.
- אין התחברות אוטומטית לחשבון Viewer ואין סיסמה ב־Netlify.
- מצב הצפייה פועל ישירות בתפקיד `viewer`, ללא Session.
- טעינה, מחיקה ושינוי נתונים נשארים חסומים בממשק.
- כניסת מנהל ממשיכה לעבוד באמצעות Supabase Auth.

## התקנה חד־פעמית
1. פתח Supabase → SQL Editor.
2. הרץ את `SPRINT_11_2_2_PUBLIC_VIEWER.sql`.
3. העלה את הפרויקט ל־GitHub/Netlify ובצע Deploy חדש.
4. ניתן למחוק מ־Netlify את `VITE_VIEWER_EMAIL` ו־`VITE_VIEWER_PASSWORD` אם נוצרו.

## אבטחה
מצב זה מאפשר לכל מי שיש לו קישור לאתר לקרוא את נתוני הדשבורד. ה־RLS מאפשר ל־`anon` פעולות SELECT בלבד; כתיבה ומחיקה נשארות למשתמשים מורשים. אין להשתמש במצב זה לנתונים סודיים שאסור לחשוף למחזיקי הקישור.

המשתמש `viewer@iml-control.local` יכול להישאר ב־Supabase או להימחק — הקוד החדש אינו משתמש בו.
